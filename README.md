## Downloading from GitHub / التحميل من GitHub

Use Code > Download ZIP, extract it, then open Command Prompt inside the extracted repository and run:

```bat
py -3.12 unpack_bundle.py
cd quran-reels
```

الخطوة دي بتسترجع نسخة v3 الأصلية كاملة، بما فيها الخط ورخصته، بعد التحقق من SHA-256. مش محتاج تنسخ أو تفك Base64 بنفسك. بعد كده كمّل تعليمات الإعداد بالأسفل من مجلد `quran-reels`. الملفات النصية الموجودة في جذر المستودع للقراءة؛ النسخة المسترجعة هي الحزمة المختبرة الأصلية. لا تستبدل مشروع قديم، فك المستودع في مجلد جديد.

The text-safe bundle preserves the exact reviewed ZIP because binary web upload was unavailable. `unpack_bundle.py` uses only Python's standard library, verifies the checksum before extracting, and makes no network requests. Run it in a fresh directory. Windows/Python 3.12 remains untested; actual tests used Linux/Python 3.10.

# Quran Reels, Python pipeline

برنامج مستقل للتشغيل من `C:\Users\USER\OpenMontage`. بيستخدم AlQuran Cloud للصوت والنص العثماني وen.sahih، وWhisper محلي عن طريق faster-whisper، وPillow للرسم وFFmpeg للتجميع. مفيش نشر تلقائي أو خدمات مدفوعة. التكلفة المستخدمة في الاختبار $0، مع احتياج إنترنت وتنزيلات ومساحة وتشغيل على جهازك.

## قبل التشغيل على ويندوز 3.12

البرنامج مش متثبت على جهازك، وما اتجربش على لابتوبك. الاختبار الفعلي كان Linux وPython 3.10.12 وFFmpeg 4.4.2. الكود مكتوب ليتوافق مع 3.12، لكن اختبار ويندوز لسه مطلوب.

فك الملفات داخل المجلد المطلوب، من غير ما تستبدل أي مشروع موجود. افتح Command Prompt:

```bat
cd /d C:\Users\USER\OpenMontage
py -3.12 --version
ffmpeg -version
ffprobe -version
py -3.12 -m pip show faster-whisper Pillow requests
```

لو البرامج موجودة وشغالة، ماتعدش تثبيتها. لو ناقصة: Python من https://www.python.org/downloads/ وFFmpeg من https://ffmpeg.org/download.html . لازم `ffmpeg` و`ffprobe` يكونوا في PATH. بعد مراجعة المتطلبات، ثبّت الناقص في بيئة منفصلة:

```bat
py -3.12 -m venv .venv-quran
.venv-quran\Scripts\activate
python -m pip install -r requirements.txt
python -c "from PIL import features; print(features.check('raqm'))"
```

الأمر الأخير لازم يطلع `True` علشان تشكيل العربي واتجاهه يبقوا صح. لو False البرنامج هيقف بدل ما يرسم عربي مكسّر. خط Amiri Quran ورخصته OFL ضمن الملفات. الخط الإنجليزي بيستخدم Arial/Calibri من ويندوز. أول تشغيل Whisper بينزّل نموذج small لو مش موجود في الكاش، حجمه مئات الميجابايت؛ مش محتاج خدمة تفريغ خارجية ولا GPU. ما تنزّلهوش لو مش موافق على التنزيل.

## تشغيل عادي صارم

```bat
python quran_reels.py --surah 13 --ayah 28 --reciter ar.abdurrahmaansudais --background "شروق فوق الحرم"
```

```bat
python quran_reels.py --surah 94 --ayah 5-6 --reciter ar.mahermuaiqly --background "night sky stars"
```

الناتج `out\13-28-v1.mp4` أو `out\94-5-6-v1.mp4`، والرقم بيزيد من غير استبدال فيديو سابق. مسار الحفظ يفضل من غير apostrophe. مدخلات الآيات خارج الحدود أو معرّف قارئ غير متاح هتسبب توقف، مش تبديل تلقائي لقارئ تاني.

معرّفات مطلوبة ممكن تجربها حسب إتاحتها من AlQuran Cloud: `ar.mahermuaiqly`، `ar.abdulbasitmurattal`، `ar.minshawi`، `ar.abdurrahmaansudais`، `ar.alafasy`، `ar.ahmedajamy`. مش كل دول اتجربوا في الاختبار ده.

## دقة الكلمات: التوقف أحسن من توقيت مخترع

Whisper ممكن يسقط كلمة أو عبارة مكررة. البرنامج بيطابق النص المسموع مع الكلمات العثمانية، مع الاحتفاظ بالنص الأصلي للعرض. علامات الوقف مش كلمات منطوقة. لو التطابق مش كامل بيستخدم محاذاة cross-attention/DTW محلية من Whisper على النص القانوني للآية. دي محاذاة صوتية، مش تقسيم المدة بالتساوي.

لو كلمة مفقودة، توقيت غير صالح، آية طويلة أكتر من نافذة المحاذاة (28 ثانية للآية عند الاحتياج للمسار ده)، أو ثقة منخفضة، الوضع الافتراضي بيقف ويترك تقرير alignment JSON داخل `out\build-*`. ما بيدّعيش إن ثقة النموذج إثبات تطابق دقيق بالمللي ثانية. المراجعة البشرية مهمة للنص الديني.

لنسخة اختبار فقط مع محاذاة كاملة لكن ثقة منخفضة:

```bat
python quran_reels.py --surah 94 --ayah 5-6 --reciter ar.mahermuaiqly --background "night sky stars" --allow-approximate
```

ده اختيار صريح، بيضيف `REVIEW` للاسم وعلامة واضحة في كل الفيديو. مش مناسب للنشر. حتى الاختيار ده مش بيخترع توقيت كلمة فشلت محاذاتها بالكامل.

## الخلفية والحقوق

البحث التلقائي من Openverse بيفلتر CC0 أو Public Domain Mark فقط، وبيحفظ اسم المصدر ورابطه والرخصة. الفلتر مش ضمان لملكية الرافع. الوصف العربي بيتحوّل لكلمات بحث محدودة زي شروق/مسجد/نجوم. مش نموذج توليد يفهم كل وصف، ومش مضمون يلاقي مكان بعينه. ما تعتبرش مسجد عام هو الحرم.

لو مفيش صورة مناسبة البرنامج بيقف. بديل صورة محلية أنت متأكد من حق استخدامها:

```bat
python quran_reels.py --surah 13 --ayah 28 --reciter ar.abdurrahmaansudais --background "mosque sunrise" --background-file "C:\Users\USER\OpenMontage\my-background.jpg"
```

اختيار صريح لتجربة خلفية جبال وشروق مرسومة برمجيًا، مش مكان حقيقي:

```bat
python quran_reels.py --surah 13 --ayah 28 --reciter ar.abdurrahmaansudais --background "sunrise" --allow-generated-background
```

الصوت متاح من AlQuran Cloud، لكن إذن إعادة نشر تسجيل كل قارئ في فيديوهات أو تحقيق دخل منه **لم يتم التحقق منه**. الوصول المجاني مش رخصة نشر. البرنامج بيحفظ رابط الصوت، وما بينشرش أي حاجة. لذلك الناتج ملف فيديو جاهز تقنيًا، مش ضمان حقوق نشر مكتملة.

## التنسيق الفعلي

- 1080×1920، 30fps، H264/AAC، من غير موسيقى. مدة التسجيل كاملة من غير قص أو تسريع علشان نوصل لرقم متوقع.
- التظليل تراكمي بالذهبي من بداية التلاوة حتى الكلمة الحالية، والكلمات التالية أبيض، مع النص العثماني `#FFD400` والباقي أبيض، مع ثبات الآية كاملة في مجموعة نصية بالمنتصف. من أول إطار فيه نص وتظليل. الترجمة 44px ومن غير كارت غامق، مع ظل خفيف حول الحروف للوضوح على الموبايل.
- ترجمة Sahih بيضاء 80% تحت العربي. بتتغير عند حدود الآية. داخل الآية، لو عدد جمل الإنجليزي وافق عدد أجزاء الوقف، بيتم التبديل عند الوقف، مش عند نصف عدد الكلمات عشوائيًا. لو ماوافقش، بتظهر ترجمة الآية كاملة. مش ترجمة كلمة بكلمة.
- العنوان فوق عربي وإنجليزي، AYAH تحت. آخر ثانية بيظهر «تابع للمزيد» واسم القارئ **مع بقاء نص الآية والتلاوة**.
- لو النص أو الترجمة أطول من مساحة العرض الآمنة البرنامج بيقف، مش بيقص الكلام خفية. اختار آيات أقصر.
- حركة zoom بسيطة للخلفية، والملفات المؤقتة في مجلد build منفصل لكل تشغيل. ما تشغّلش عمليتين على نفس اسم الناتج في نفس اللحظة.

## الاختبارات اللي اتعملت

1. الرعد 13:28 بالسديس: تنزيل فعلي، Whisper محلي ومحاذاة canonical لكل 11 كلمة، FFmpeg، ثم فحص صور من البداية والوسط والنهاية. 13.845 ثانية، 1080×1920/30fps، H264/AAC. المدة حوالي 14 ثانية مش متثبتة عند 15. الخلفية مسجد وقت شروق من Rawpixel CC0، **مش ادعاء إنه الحرم**. رابطها في TEST_RESULTS.md.
2. الشرح 94:5-6 بالمُعيقلي: تنزيل الآيتين وتركيبهم، 5.46 ثانية. الوضع الصارم وقف بسبب ثقة 0.0796 في كلمة «مع» في 94:5. نسخة REVIEW الاختيارية اتجمعت واتراجعت بصريًا، تغيير AYAH5 إلى6 والترجمة شغال، لكن ده مش نجاح دقة كامل.
3. الاختبارات المحلية للوحدات: `python -m unittest -v test_quran_reels.py` .
4. غير مختبر: ويندوز/Python3.12، كل القراء، كل الآيات الطويلة، كل أوصاف الخلفيات. النموذج والتوقيت الآلي ممكن يحتاجوا مراجعة، لذلك البرنامج الصارم لا يضمن نجاح كل إدخال بلا تدخل.

ما ادّعيناش مطابقة بكسل لبكسل لفيديوهات Duha/Ayat al-Kursi الموجودة على لابتوبك لأن الملفات دي مش متاحة هنا. التنسيق اتبنى على مواصفاتك والمرجع: https://github.com/asdd220977-svg/quran-reels-prompts .

## استكشاف المشاكل

- `ffmpeg not found`: أضف مجلد bin إلى PATH وافتح Command Prompt جديد.
- API timeout / 429: اقفل المحاولة واستنى، ماتعملش loop سريع. جرّب لاحقًا.
- `Low-confidence`: راجع JSON، ما تغيّرش حد الثقة علشان تخفي المشكلة. REVIEW للاستماع والفحص فقط.
- `No suitable licensed stock`: اختار صورة محلية مناسبة مرخصة أو جرّب وصف أبسط؛ الخلفية المولدة اختيار صريح فقط.
- `Canonical word alignment incomplete`: مفيش فيديو سليم اتعمل؛ ما تعتمدش على ملفات أقدم باعتبارها نتيجة التشغيل الجديد.
